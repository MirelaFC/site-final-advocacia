# Site Institucional - Sousa & Abreu Advocacia
![Página inicial do site](previa_site.png)

Website institucional desenvolvido para apresentação profissional do escritório Sousa & Abreu Advocacia.

## Sobre o projeto

Projeto desenvolvido como parte da minha retomada na área de desenvolvimento web.

O objetivo foi criar uma presença digital para o escritório, apresentando informações institucionais, áreas de atuação e canais de contato.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Funcionalidades

- Página institucional
- Navegação entre seções
- Layout responsivo
- Integração com WhatsApp
- Integração com Instagram

## Site publicado

https://sousaeabreu.adv.br/
